that session feed straight into this package.

## Machine-element inventory (6 points)

Name every recognizable element and measure it. "Spur pinion, 11 teeth, module
about 0.8" beats "gear". Photograph each element and tag it. Bag fasteners by
subsystem and photograph the bags.

## Teardown video (4 points)

**Required.** It shows the documentation standard being followed: each subsystem
photographed *before* it is opened. Put the link in [`video-link.md`](video-link.md).

## Load-path free-body diagrams (6 points)

One free-body diagram per operating state you identify, such as idle, normal
use, and jam or overload. Show where load enters, what carries it, and where it
reacts out. Your system boundary is a choice, so state it.

## Photos (2 points)

Captioned and organized by subsystem. A camera-roll dump of loose parts is worth
2 of the 20 points in this package; the same photos organized by subsystem with
captions are worth all of them.

**Photograph before you open.** You cannot recover a "before" photo after the
cover is off.

## Safety record (2 points)

Document the energy-isolation steps from the [project README](../README.md) with
photos: battery pack removed and stored in another member's custody, springs
identified before release, eye protection worn. This is the easiest 2 points in
the project.
