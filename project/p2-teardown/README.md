## Photograph before you open

The documentation standard is: photograph each subsystem *before* you open it.
A camera-roll dump of loose parts is worth 2 of 20 points; the same photos
organised by subsystem with captions are worth all of them.

## Inventory

Name every recognizable element — "spur pinion, 11 teeth, module ~0.8" beats
"gear". Bag fasteners by subsystem and photograph the bags.

## Load-path FBDs

One free-body diagram per operating state you identify (idle, normal use, jam or
overload). Show where load enters, what carries it, and where it reacts out.
Your system boundary is a choice — state it.

## Safety record

Document the energy-isolation steps from the project README with photos: pack
removed and stored, springs identified before release, eye protection worn.
This is 2 points and it is the easiest 2 points in the project.
