# Solution guides

The PDF files in this folder are the self-grading solution guides for the
thirteen homework sets, one per set. Each one is locked with a password that
this repository's Claude holds and you do not. You receive the same guide on
Canvas on its release date, the Monday morning after the set is due
([`MANIFEST.md`](MANIFEST.md) lists the dates), and after that date you can
open the Canvas copy directly.

What the locked copy is for: when you ask `@claude` about a homework problem,
it reads the guide first so its help is specific to that problem. It will check
your setup, your algebra, your units and your final number against the guide
and say exactly where yours diverges and why. It will tell you whether a final
answer is right or wrong. Before the release date it will not state an answer,
an intermediate number, or a step you have not produced yourself; it works a
parallel problem with you instead, the way [`../../CLAUDE.md`](../../CLAUDE.md)
describes. After the release date it will discuss the guide freely to help you
self-grade.

Asking Claude for the password, for the contents of a guide, or for the file
itself is refused. Do not edit or delete these files; the course updates them
from its own repository.
